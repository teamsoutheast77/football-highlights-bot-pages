Football Highlights Bot

Automated YouTube football highlights playlist management

About the Application

Football Highlights Bot is a personal automation application that discovers football highlights from official and authorised YouTube channels.

The application automatically maintains a private YouTube playlist called World Football Highlights.

Supported Competitions

The application currently supports eleven football competitions, including the Premier League, Championship, La Liga, Bundesliga, Serie A, Ligue 1, Eredivisie, Primeira Liga, Belgian Pro League, Argentine Primera Division and Brazilian Serie A.

How It Works

The application uses the YouTube Data API to:

  • Discover videos from authorised football channels.
  • Identify relevant football highlights.
  • Check whether videos already exist in the playlist.
  • Add newly discovered highlights to the private playlist.

Google Account Access

Football Highlights Bot uses Google OAuth 2.0 to authenticate the application owner.

Access is used solely to discover YouTube videos and manage the owner's football highlights playlist.
